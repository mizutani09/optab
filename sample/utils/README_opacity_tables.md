# Opacity Lookup Table HDF5 Structure Documentation

This document describes the structure and usage of the HDF5 opacity lookup table generated by the optab stellar opacity calculation program.

## Overview

The opacity calculation program generates an optimized HDF5 lookup table for fast interpolation:

**2D Format** (`opacity_lookup_table_2d.h5`) - For regular grids and fast interpolation ⭐ **RECOMMENDED**

## File Structure

### 2D Format: `opacity_lookup_table_2d.h5` ⭐ **RECOMMENDED**

```
/
├── log_temperature      [1D array: 21 elements, double precision]  # Log10 temperature grid points
├── log_density          [1D array: 21 elements, double precision]  # Log10 density grid points
├── planck_mean_opacity  [2D array: 21×21, double precision]        # opacity[log_density_idx, log_temp_idx]
├── rosseland_mean_opacity [2D array: 21×21, double precision]      # opacity[log_density_idx, log_temp_idx]
└── @attributes:
    └── grid_structure: "2D grid: opacity[i,j] corresponds to log_density[i] and log_temperature[j]"
```

**Structure Description:**
- Log temperature grid: 21 logarithmically spaced points from log₁₀(316) to log₁₀(31.6×10⁶) K
- Log density grid: 21 logarithmically spaced points per temperature
- Grid indexing: `opacity[i,j]` = opacity at `10^log_density[i]` and `10^log_temperature[j]`
- Memory efficient: Optimized 2D storage format with logarithmic coordinates

## Data Ranges and Units

| Parameter | Range | Units | Description |
|-----------|-------|-------|-------------|
| Log Temperature | log₁₀(3.16×10²) - log₁₀(3.16×10⁷) | log₁₀(K) | Log₁₀ of stellar interior temperature range |
| Log Density | log₁₀(8.89×10⁻¹⁵) - log₁₀(8.89×10⁻²) | log₁₀(g/cm³) | Log₁₀ of matter density range |
| Planck Mean Opacity | 7.38×10⁻⁴² - 1.44×10¹ | cm²/g | Frequency-averaged opacity (Planck function weighting) |
| Rosseland Mean Opacity | 8.10×10⁻²⁵ - 2.74×10⁰ | cm²/g | Frequency-averaged opacity (flux weighting) |

## Attributes and Metadata

Each dataset includes the following HDF5 attributes:

- **`units`**: Physical units (log₁₀(K), log₁₀(g/cm³), cm²/g)
- **`description`**: Human-readable description of the dataset
- **File-level attributes**:
  - `grid_structure`: Description of the data organization

## Usage Examples

### Python: Loading 2D Format

```python
import h5py
import numpy as np

# Load 2D opacity table
with h5py.File('opacity_lookup_table_2d.h5', 'r') as f:
    log_temp_grid = f['log_temperature'][:]           # 21 points (log10 K)
    log_rho_grid = f['log_density'][:]                # 21 points (log10 g/cm³)
    planck_2d = f['planck_mean_opacity'][:]           # 21×21 grid
    rosseland_2d = f['rosseland_mean_opacity'][:]     # 21×21 grid

# Fast bilinear interpolation in log space
def interpolate_opacity_2d(target_temp, target_rho):
    # Convert to log space
    log_target_temp = np.log10(target_temp)
    log_target_rho = np.log10(target_rho)
    
    # Find grid indices
    i = np.searchsorted(log_temp_grid, log_target_temp)
    j = np.searchsorted(log_rho_grid, log_target_rho)
    
    # Clamp to grid boundaries
    i = np.clip(i, 1, len(log_temp_grid)-1)
    j = np.clip(j, 1, len(log_rho_grid)-1)
    
    # Bilinear interpolation weights in log space
    t_frac = (log_target_temp - log_temp_grid[i-1]) / (log_temp_grid[i] - log_temp_grid[i-1])
    r_frac = (log_target_rho - log_rho_grid[j-1]) / (log_rho_grid[j] - log_rho_grid[j-1])
    
    # Interpolate (opacity[log_rho_idx, log_temp_idx])
    p11, p12 = planck_2d[j-1,i-1], planck_2d[j,i-1]
    p21, p22 = planck_2d[j-1,i], planck_2d[j,i]
    
    planck = (1-t_frac)*(1-r_frac)*p11 + (1-t_frac)*r_frac*p12 + \
             t_frac*(1-r_frac)*p21 + t_frac*r_frac*p22
             
    return planck  # Similar for Rosseland
```

### C/C++: Loading Data

```cpp
#include <hdf5.h>

// Load 2D opacity table
hid_t file_id = H5Fopen("opacity_lookup_table_2d.h5", H5F_ACC_RDONLY, H5P_DEFAULT);

// Read log temperature grid
hid_t temp_dataset = H5Dopen(file_id, "/log_temperature", H5P_DEFAULT);
double log_temperature[21];
H5Dread(temp_dataset, H5T_NATIVE_DOUBLE, H5S_ALL, H5S_ALL, H5P_DEFAULT, log_temperature);
H5Dclose(temp_dataset);

// Read 2D opacity grid
hid_t opacity_dataset = H5Dopen(file_id, "/planck_mean_opacity", H5P_DEFAULT);
double opacity[21][21];
H5Dread(opacity_dataset, H5T_NATIVE_DOUBLE, H5S_ALL, H5S_ALL, H5P_DEFAULT, opacity);
H5Dclose(opacity_dataset);

H5Fclose(file_id);

// Access: opacity[log_density_index][log_temp_index]
```

### Fortran: Loading Data

```fortran
program read_opacity
    use hdf5
    implicit none
    
    integer(HID_T) :: file_id, dset_id
    integer :: error
    real(8) :: log_temperature(21), log_density(21)
    real(8) :: planck_opacity(21,21), rosseland_opacity(21,21)
    
    ! Initialize HDF5
    call h5open_f(error)
    
    ! Open file
    call h5fopen_f('opacity_lookup_table_2d.h5', H5F_ACC_RDONLY_F, file_id, error)
    
    ! Read log temperature grid
    call h5dopen_f(file_id, '/log_temperature', dset_id, error)
    call h5dread_f(dset_id, H5T_NATIVE_DOUBLE, log_temperature, [21], error)
    call h5dclose_f(dset_id, error)
    
    ! Read 2D opacity grid
    call h5dopen_f(file_id, '/planck_mean_opacity', dset_id, error)
    call h5dread_f(dset_id, H5T_NATIVE_DOUBLE, planck_opacity, [21,21], error)
    call h5dclose_f(dset_id, error)
    
    call h5fclose_f(file_id, error)
    call h5close_f(error)
    
    ! Access: planck_opacity(i,j) for log_density(i), log_temperature(j)
end program
```

## Grid Structure Details

The opacity calculations are performed on a **regular 21×21 logarithmic grid**:

- **Temperature points**: 21 values logarithmically spaced from log₁₀(316) to log₁₀(31.6×10⁶) K
- **Density points**: 21 values per temperature, logarithmically spaced in log₁₀ space
- **Total combinations**: 21 × 21 = 441 unique (log₁₀T, log₁₀ρ) pairs
- **Physical coverage**: Stellar interior conditions from cool atmospheres to hot cores

## Data Generation

The opacity tables are generated by:

1. **Source calculations**: Individual HDF5 files for each (T,ρ) combination
2. **Data extraction**: `create_opacity_table_2d.cpp`
3. **Grid detection**: Automatic recognition of regular grid structure
4. **Format optimization**: Optimized 2D storage format
